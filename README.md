# Skills Distribution Portal

内部技能分发页，当前主版本为 WPS Comate。

## 发布内容

- `index.html`：可直接静态托管的单文件页面
- GitHub Pages：<https://zhaochun1003-bot.github.io/skills-distribution-portal/>

## 维护方式

1. 替换 `index.html` 底部 `DOWNLOAD_LINKS` 中的真实下载地址。
2. 更新页面中的版本号、更新时间与更新记录。
3. 将仓库发布到 GitHub Pages、GitLab Pages 或任意静态站点服务。
