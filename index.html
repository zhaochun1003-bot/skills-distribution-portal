Guide

使用说明

先完成入口判断，再导入对应版本并用示例输出做一次验证。

直接给团队使用 从 WPS Comate 开始。
维护规则和样例 使用 Claude Skill。
验证跨平台效果 使用 GPTs。

如何开始

  • 优先进入 WPS Comate，确认是否满足本次评审场景。
  • 导入技能或提示词后，准备待审核方案文档与规则文件。
  • 先用 Compact 或 Standard 示例校准输出，再交给团队使用。

如何维护

  • Core 只维护一套：角色边界、输出结构与短版约束统一维护。
  • WPS Comate 持续作为主生产版本。
  • 各平台只维护格式差异、入口文案与知识承载方式。
